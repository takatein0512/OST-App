# OST-App

OST（Open Space Technology）の会で使う、マーケットプレイスボード（時間割）のローカルアプリです。
参加者がスケッチブックに書いたテーマをMacのカメラで撮り、時間とテーブルのマスに貼って、そのままプロジェクタに映せます。
外部サービスもAPIキーも `npm install` も要りません。Node.js だけで動きます。

## できること

- カメラで撮影し、その場でカードとして登録する。ファイルからの登録もできる
- 時間枠 × テーブルのマスにカードをドラッグして配置する。クリックで編集と削除
- 投影用の画面を別ウィンドウで開く。操作側の変更はリロードなしで反映される
- 撮影した写真の文字をローカルのOCRで読み取り、テーマ欄に入れる（任意）
- 時間枠とテーブルの数を設定画面で増減する
- ボードをJSONで書き出す。印刷とPDF化もできる

## 必要なもの

- Node.js 18 以上
- Mac のブラウザ（カメラを使うため。Chrome を想定しています）
- 文字起こしを使う場合のみ [Ollama](https://ollama.com/) と `glm-ocr` モデル（約2.2GB）

## 起動

```bash
git clone https://github.com/takatein0512/OST-App.git
cd OST-App
node server.js
```

Finder から `start.command` をダブルクリックしても起動できます。Ollama が止まっていれば先に起動し、サーバーを立てて、ブラウザも開きます。

| URL | 用途 |
|---|---|
| http://localhost:5173/ | 操作用。撮る、ボード、設定 |
| http://localhost:5173/?view=stage | 投影用。別ウィンドウで開いてプロジェクタへ |

止めるときは Ctrl+C です。ポートを変えるなら `PORT=8080 node server.js` とします。

## 使い方

1. 「撮る」タブでカメラを許可します。初回だけです。
2. スケッチブックを写して撮影します。スペースキーでも撮れます。
3. テーマ名と言い出した人は任意です。写真に書いてあるならそのままで構いません。
4. 時間とテーブルを選んで「ボードに追加」を押します。選ばずに追加すると「未配置」に入り、あとから貼れます。
5. 「ボード」タブでカードをドラッグして入れ替えます。
6. 「投影を開く」を押すと、投影用のウィンドウが開きます。

カメラ権限は当日その場だと焦るので、事前に「撮る」タブを一度開いて許可しておくと安心です。
投影ウィンドウは横1600px以上あると8テーブルが1画面に収まります。狭いときは設定でテーブル数を減らしてください。

## 文字起こし（ローカルOCR）

撮影と同時に読み取りが走り、1〜2.5秒ほどでテーマ欄に文字が入ります。違っていればその場で直せます。
モデルは Ollama 上の `glm-ocr` で、会場のネットワークは要りません。

```bash
ollama pull glm-ocr   # 初回のみ
ollama serve          # 別タブで動かしっぱなしにする
```

- 読み取りは撮影と並行して走るので、登録を待たされません
- テーマ欄に自分で打ってあるときは上書きしません
- Ollama が動いていない、または読めなかったときは空欄のままで、運用は止まりません
- 止めたいときは設定タブの「撮影したら自動で読み取る」をOFFにします
- サーバーを起動してからターミナルに「OCR 準備完了」と出るまで、30秒〜1分かかります。開始前に立ち上げておいてください

手元で測った値は、スケッチブック1行が1.1〜2.5秒、文字だらけの本の表紙が3〜8秒でした。
活字はほぼ正確に読めますが、`LLM` が `LM` になるような細かい誤読はあります。
遅いと感じたら、`server.js` の生成量の上限 `num_predict` を下げてください。この値を外すと、モデルが同じ行を延々と出し続けて数十秒かかります。

## カメラの選び方

画面上部のドロップダウンで切り替えます。
MacBook内蔵カメラは、前に出てスケッチブックを掲げてもらうときに向いています。
机に置いた紙を上から撮るなら、iPhone（連係カメラ）のほうが画質がよく、同じ Apple ID でロック解除して近くに置くと一覧に出てきます。
映らないときは「ファイルから」で写真を選んでも登録できます。

## 保存先

| 場所 | 中身 |
|---|---|
| `data/board.json` | 時間枠、テーブル、カードの配置 |
| `data/photos/` | 撮影した写真（長辺1600pxのJPEG） |
| `data/history/` | 保存のたびの退避。直近40件。操作を誤ったときはここから戻す |

`data/` は初回起動で自動的にできます。`.gitignore` で除外しているので、撮った写真や参加者のテーマがリポジトリに入ることはありません。

## 他の端末から見せたいとき

起動時に表示される `http://<LAN IP>:5173/` を同じWi-Fiの端末で開けば、閲覧はできます。
ただしカメラが使えるのは `localhost` だけです。ブラウザの仕様で、http の他ホストではカメラAPIが動きません。
会場のゲストWi-Fiは端末間の通信を塞いでいることが多いので、撮影も配置もMac 1台で済ませるのが確実です。

## リハーサル

ダミーのテーマを8枚入れて、見た目を試せます。サーバーを起動した状態で実行してください。
Pillow（`pip install pillow`）と、macOS 標準のヒラギノ角ゴシックを使います。

```bash
python3 tools/seed-dummy.py
```

消すときは設定タブの「カードを全消去」を使います。

## 構成

```
server.js          HTTPサーバー、ボードの保存、OCR呼び出し
public/            操作画面と投影画面（HTML / CSS / JS）
assets/warmup.jpg  OCRモデルの暖機用の画像
tools/             リハーサル用のダミーデータ投入
start.command      Finder から起動するためのスクリプト
```
